# MarkID — 계약서 주민등록번호 마스킹 도구

계약서(PDF·이미지)에서 **주민등록번호**(및 선택 시 **주소**)를 찾아, 원본 데이터를
**실제로 제거(redaction)** 한 뒤 검은 박스 또는 모자이크로 가린 사본을 만드는
Windows 프로그램입니다.

- **완전 오프라인**: 네트워크 접속이 전혀 없습니다. 모든 처리는 로컬에서 이루어집니다.
- **진짜 삭제**: 단순히 위에 덮는 것이 아니라, 텍스트·이미지 픽셀을 PDF에서 제거한 뒤 가립니다.
- **신분증 사진까지**: 내장 OCR(한국어)이 계약서에 첨부된 운전면허증·신분증
  사진(회전된 사진 포함)과 진위조회 화면 속 번호까지 찾아냅니다.
- **PDF 리더 불필요**: 프로그램 안에서 원본과 결과를 바로 미리보기할 수 있습니다.

---

## 1. 설치 및 실행

### 방법 A: 단일 실행 파일 (권장)
`MarkID.exe` 한 개만 있으면 됩니다. 설치가 필요 없습니다. 더블클릭하면 GUI가 열립니다.

### 방법 B: 소스에서 실행
```
pip install -r requirements.txt
python -m markid          # GUI 실행
```
> OCR 모델 파일(`models\korean_rec.onnx`, `models\korean_dict.txt`)이 프로젝트에
> 포함되어 있어야 합니다.

## 2. 화면(GUI) 사용법

1. **파일 추가**: 왼쪽 위 `[파일 추가]`로 PDF 또는 이미지(JPG/PNG/BMP/TIFF)를 여러 개 선택합니다.
2. **옵션 설정** (왼쪽):
   - **마스킹 범위**
     - `주민등록번호 전체` — 13자리 전부 가림
     - `뒷 6자리만` *(기본값)* — 예: `900101-2●●●●●●` 처럼 뒷 6자리만 가림
   - `주소도 마스킹` *(기본 해제)* — 자택/회사/상세주소 및 신분증 속 주소도 가림
   - `이미지 OCR 검사` *(기본 체크)* — 신분증 사진 등 이미지 속 번호 검사
   - **마스킹 방식**: `검은색 박스` *(기본)* 또는 `모자이크`
   - **출력 폴더**: 비워 두면 `원본폴더\masked\` 에 저장됩니다.
   - `페이지 PNG로도 저장` — 결과를 페이지별 PNG(150dpi)로도 저장
3. **① 검사 (미리보기)**: 문서를 분석해 오른쪽에 검출 목록과 빨강/파랑 표시를 보여줍니다.
   (OCR 포함 시 문서 크기에 따라 수십 초~수 분 걸릴 수 있습니다.)
4. **검출 결과 확인/수정** (오른쪽):
   - 목록의 체크(☑)를 해제하면 그 항목은 마스킹에서 **제외**됩니다.
   - 행을 더블클릭하면 해당 페이지로 이동하고 위치를 강조합니다.
   - 미리보기 색: **빨강=주민번호, 파랑=주소, 초록=수동 지정, 회색 점선=제외됨**
   - `수동 영역 추가: 켜짐` 상태에서 미리보기를 **드래그**하면 원하는 영역을 직접 지정할 수 있습니다.
5. **② 마스킹 실행**: 체크된 항목만 마스킹해 사본을 저장하고, 자동으로 `결과` 미리보기로 전환됩니다.
   - 위쪽 `원본 보기 / 결과 보기` 버튼으로 비교할 수 있습니다.
   - (검사 없이 실행을 누르면 자동으로 검사 후 이어서 마스킹까지 진행합니다.)
6. **③ 전체 파일 일괄 처리**: 파일 목록의 모든 파일을 현재 옵션으로 한 번에 검사·마스킹·저장합니다. 파일별 결과(검출 수, 저장 위치)는 진행 로그에 표시되며, 오류가 있는 파일은 건너뛰고 계속합니다.
7. **초기화 (파일 닫기)**: 열려 있는 문서 핸들을 모두 닫아 파일을 이동/삭제할 수 있게 하고, 현재 파일을 목록에서 제거하며 검출 목록·미리보기·글자 수정 내역을 비웁니다(남은 파일은 목록에 유지).
8. **글자 수정 (텍스트 교체)**: `글자 수정: 켜짐` 상태에서 미리보기의 글자를 **드래그로 선택**하면
   원본 텍스트가 표시된 입력창이 열립니다. 새 텍스트를 입력하고 `적용`을 누르면 원래 글자는
   실제로 제거되고 같은 자리에 새 텍스트가 같은 크기·색으로 들어갑니다(주황 테두리 표시,
   목록에서 체크 해제하면 되돌아갑니다).
   - **스캔(사진) 문서의 글자는 수정할 수 없습니다** — 텍스트 레이어가 있는 PDF만 지원합니다.
   - 새 텍스트가 원래 자리보다 길면 자동으로 글자가 축소되어 들어갑니다.
   - **주의**: 서명·날인이 완료된 계약서의 내용 수정은 문서 변조 등 법적 문제가 될 수 있습니다. 반드시 수정 권한이 있는 문서에만 사용하세요.
9. **화면 조작**: 미리보기와 검출 목록 사이의 **분할바를 드래그**해 두 영역의 높이를 조절할 수 있습니다.
   확대/축소는 `－`/`＋` 버튼, `창맞춤`(100%), 또는 **Ctrl+마우스 휠**로 조작합니다(25%~400%).

## 3. 명령줄(CLI) 사용법

```
MarkID.exe --cli --input a.pdf [b.pdf ...] [옵션]
```

| 옵션 | 설명 |
|---|---|
| `--input FILE ...` | 입력 파일(PDF/이미지) 하나 이상 |
| `--scope full\|back6` | `full`=전체, `back6`=뒷 6자리 (기본 `back6`) |
| `--style box\|mosaic` | 마스킹 방식 (기본 `box`) |
| `--address` | 주소도 마스킹 |
| `--no-ocr` | 이미지 OCR 끄기(텍스트 레이어만 검사, 빠름) |
| `--outdir DIR` | 출력 폴더 (기본 `원본폴더\masked`) |
| `--report r.json` | 검출 내역·출력 경로를 UTF-8 JSON으로 저장 |
| `--png` | 페이지별 PNG도 저장 |
| `--selftest` | GUI 구성 확인 후 종료(정상 시 종료코드 0) |

**예시**
```
MarkID.exe --cli --input 계약서.pdf --scope full --style box --address --report out.json
```

- 종료 코드: `0` 정상, `2` 입력 오류 또는 처리 실패.
- 인자 없이 실행하면 GUI가 열립니다.
- 콘솔 출력은 진행 상황 위주(영문)이며, 자세한 결과는 `--report` JSON을 확인하세요.

## 4. 검출 규칙 요약

- **주민등록번호(완전형)**: `YYMMDD-Gxxxxxx` (성별자리 1~8). 사업자등록번호(3-2-5),
  계좌·면허·전화번호, 날짜(`2023.12.26`), 조항번호 등은 자릿수/구분자 규칙으로 걸러냅니다.
- **주민등록번호(앞자리형)**: `주민번호` 라벨 옆에 있거나, 신분증/진위조회 이미지 안에 있는
  앞 6자리. `뒷 6자리만` 모드에서는 이미 가려진 상태로 보고 건너뜁니다.
- **사진(이미지) 속 번호**: 위치 추정 한계로 `뒷 6자리만` 모드에서도 번호 **전체**를 가립니다.
- **주소** *(옵션 ON)*: 시/도 + 도로명 + 번지 형태(예: `서울 강남구 테헤란로 123`), `동/호`
  상세주소, 그리고 신분증 이미지에서 주민번호 아래의 주소 영역을 함께 가립니다.

## 5. 제한 사항 및 주의

- **암호(비밀번호)로 보호된 PDF는 지원하지 않습니다.** 암호를 해제한 뒤 사용하세요.
- OCR은 인쇄·스캔 상태에 따라 일부 글자를 놓치거나 잘못 읽을 수 있습니다. **결과 PDF를
  반드시 육안으로 확인**하세요. 특히 저해상도·심하게 기울어진 신분증 사진은 검출률이 낮을 수 있습니다.
- 자동 검출은 보조 수단입니다. 누락이 우려되면 `수동 영역 추가`로 직접 가리거나, 검사 결과를
  확인 후 실행하세요.
- 마스킹된 사본은 되돌릴 수 없습니다(원본 데이터가 제거됨). **원본은 항상 별도 보관**하세요.
- 이 프로그램은 원본 파일을 수정하지 않으며, 결과는 항상 새 사본으로 저장됩니다.

## 6. 개인정보 처리

- 모든 처리는 사용자 PC 안에서만 이루어지며, 어떤 데이터도 외부로 전송되지 않습니다.
- OCR 모델은 프로그램에 포함된 로컬 파일만 사용합니다.
